====================================================================
  SPRITE GUIDE — Dungeon Crawler Roguelike
  Replaces the colored placeholder shapes in BootScene.js
====================================================================

HOW TO ADD A SPRITE
-------------------
1. Save your PNG into assets/sprites/<key>.png
2. In src/scenes/BootScene.js, load it in the preload() method:
     this.load.image('key', 'assets/sprites/key.png');
3. Remove the matching this._make*() call in create() for that key.
4. Make sure the texture dimensions match the notes below so hitboxes
   stay correct. If you resize, update body.setSize() in the entity.


====================================================================
  PLAYER
====================================================================
Key:         player
File:        assets/sprites/player.png
Canvas size: 28 × 28 px   (or any power-of-two, keep it square)
Hitbox:      22 × 22 px centred

What to draw:
  A top-down hero character viewed from above.
  - Body should face downward (south) in the default frame.
  - Colour palette: greens / teals (to distinguish from enemies).
  - Optional: add 4-direction walk frames as a spritesheet:
      Sheet layout: 4 columns × 4 rows
      Columns: down, left, right, up
      Rows: idle + 3 walk frames
      Each frame: 28 × 28 px → sheet: 112 × 112 px
      Then load with:
        this.load.spritesheet('player', 'assets/sprites/player.png',
          { frameWidth: 28, frameHeight: 28 });
      And in Player.js add anims.create() calls.

Placeholder appearance:
  Green rounded rectangle body, lighter green head, black dot eyes.

---- SLIME ----
Key:         enemy_slime
File:        assets/sprites/enemy_slime.png
Canvas size: 28 × 28 px
Hitbox:      22 × 22 px

What to draw:
  A small, round, gelatinous blob.

====================================================================
  ENVIRONMENT
====================================================================

---- FLOOR TILE ----
Key:         tileset  (tile index 1, pixel offset x=32)
Canvas size: 32 × 32 px  (part of a 96 × 32 px strip)

What to draw (tile 1 of 3 in strip):
  Dark stone floor tile.
  - Subtle texture: cracks, mortar lines, or cobblestone pattern.
  - Dark grey / dark blue-grey palette.
  - Tileable (edges should connect seamlessly).

---- WALL TILE ----
Key:         tileset  (tile index 2, pixel offset x=64)
Canvas size: 32 × 32 px

What to draw (tile 3 of 3 in strip):
  Stone dungeon wall.
  - Clearly darker / more solid than floor.
  - Bricks or rough stone texture.
  - Should look like the top face of a wall block.

HOW TO REPLACE THE TILESET:
  1. Create a 96 × 32 image with 3 tiles side by side:
       x=0:  black void
       x=32: floor tile
       x=64: wall tile
  2. Save as assets/sprites/tileset.png
  3. In BootScene.js, add to preload():
       this.load.image('tileset', 'assets/sprites/tileset.png');
  4. Remove the this._makeTileset() call from create().
  5. No other changes needed — the tilemap system already uses 'tileset'.

====================================================================
  NOTES ON ANIMATION
====================================================================
The current game uses static sprites only.
To add walking animations:
1. Create spritesheets with frames laid out in a single row or grid.
2. Load with this.load.spritesheet() instead of this.load.image().
3. In the entity constructor, call:
     this.anims.create({ key: 'walk', frames: ..., frameRate: 8, repeat: -1 });
     this.anims.play('walk');
4. In update(), switch animation based on velocity direction.
